# 🎀 Lumière — Little Gifts. Big Feelings.

> A cute and modern gift store website created as part of my Git & GitHub practical assignment.

---

## 🩵 About the Project

**Lumière** is a simple online gift store designed for people looking for thoughtful gifts for their friends, family, and loved ones.

The website features a soft, modern design with curated gift categories, product cards, and an interactive shopping cart.

---

## ✨ Features

- 🏠 Modern homepage
- 🎁 Gift categories
- 🛍️ Product showcase
- 🖼️ Product images
- 🛒 Interactive shopping cart
- 💰 Automatic cart total
- ❌ Remove items from cart
- 📱 Responsive design for mobile devices
- ✉️ Newsletter subscription section
- 🎀 Soft pastel-themed UI

## 🌿 Git & GitHub Workflow

This project was developed using Git and GitHub version-control practices.

### Feature Branches

- `feature/homepage` — Homepage development
- `feature/styling` — Website styling
- `feature/navbar` — Navigation and welcome message

The repository also demonstrates:

- Feature branching
- Multiple commits
- Fast-forward merging
- Three-way merging
- Merge conflict creation
- Merge conflict resolution
- Remote repository management

---

## 🔀 Merge Conflict

A deliberate merge conflict was created while modifying the same README content on the `main` branch and `feature/navbar` branch.

The conflict was manually resolved and the final version was committed to `main`.

## 🚀 How to Run

### Option 1 — Open directly

Open `index.html` in a web browser.

### Option 2 — Using VS Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Start **Live Server**.
4. The website will open in your browser.
